Lets check some common font Properties


    font-family → sets the typeface.
    p {
    font-family: Arial, Helvetica, sans-serif;
    }


    You can list multiple fonts (fallbacks).
    "sans-serif", "serif", "monospace" are generic families.
    font-size → controls size of the text.
    h1 {
    font-size: 32px; /* pixels */
    }
    
Font Size

    p {
    font-size: 1.2em; /* relative to parent */
    }
    
Font Size


    font-weight → controls thickness.
    h1 {
    font-weight: bold; /* or numbers: 100 → 900 */
    }
    
font weight

    font-style → italic or normal.
    em {
    font-style: italic;
    }
    
font-style


    line-height → space between lines.

    p {
    line-height: 1.6;
    }

    
font line-height


    font-variant → small-caps.
    h2 {
    font-variant: small-caps;
    }
    
    
font-variant



    🎨 Shorthand Property
    Instead of writing separately, you can combine them:
    p {
    font: italic small-caps bold 16px/1.5 "Times New Roman", serif;
    }

    
Combining every Properties


    Order:
    font-style → font-variant → font-weight → font-size/line-height → font-family

    🌐 Using Google Fonts
    To use custom fonts:
    
    body {
    font-family: "Roboto", sans-serif;
    }
